# 智能仓储数字孪生看板

Vue 3 + Three.js + ECharts + Element Plus 实现的中文仓储看板。参考双立柱托盘堆垛机图片建模：双立柱、上横梁、上下导轮、安全梯、检修平台、提升钢丝绳、载货台、货叉及提升/行走电机。模型为示意模型，不作为工程尺寸依据。

## 开发

需要 Node.js 20.19+ 或 22.12+（当前验证版本为 24）。

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run build
npm run preview
```

使用支持 WebGL 的现代浏览器访问开发服务器。拖动旋转，滚轮缩放；点击堆垛机或右侧设备卡片查看设备信息。顶部视角菜单可切换俯视图，底部可暂停/继续仿真、复位视角。窄屏自动切换纵向布局。

## 数据与模型

所有 KPI、作业任务、设备状态与趋势均为固定演示数据；堆垛机运动为本地动画，不表示真实设备运行或完整作业仿真。货架共 220 个货位，按场景规则生成 187 个占用货位。设备载荷、额定参数为演示设定。当前不需要 API 密钥、数据库或后端服务。

`src/warehouse.js` 管理三维场景与设备模型，`src/App.vue` 管理看板、统计图及交互。后续可将 WMS/WCS API 或 WebSocket 状态接入 Vue 响应式数据，并用真实设备坐标驱动三维模型。
