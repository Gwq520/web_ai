# 智能仓储数字孪生看板

Vue 3 + Three.js + ECharts + Element Plus 实现的中文仓储看板。参考双立柱托盘堆垛机图片建模：双立柱、上横梁、上下导轮、安全梯、检修平台、提升钢丝绳、载货台、货叉及提升/行走电机。模型为示意模型，不作为工程尺寸依据。

## 开发

需要 Node.js 20.19+ 或 22.12+（当前验证版本为 24）。

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run build
npm run preview
```

使用支持 WebGL 的现代浏览器访问开发服务器。拖动旋转，滚轮缩放；点击堆垛机或右侧设备卡片查看设备信息。顶部视角菜单可切换俯视图，底部可暂停/继续仿真、复位视角。窄屏自动切换纵向布局。

## 数据与模型

所有 KPI、作业任务、设备状态与趋势均为固定演示数据；堆垛机运动为本地动画，不表示真实设备运行或完整作业仿真。货位总数和占用数量由当前生成的货架布局计算。设备载荷、额定参数为演示设定。当前不需要 API 密钥、数据库或后端服务。

`src/warehouse.js` 管理三维场景与设备模型，`src/App.vue` 管理看板、统计图及交互。后续可将 WMS/WCS API 或 WebSocket 状态接入 Vue 响应式数据，并用真实设备坐标驱动三维模型。

## 页面优化

参考上传视频补充蓝色托盘、纸箱、滚筒输送线、护栏和控制柜。货架及货物使用 InstancedMesh 批量渲染。支持货架透视、设备特写跟随、选中设备高亮以及 0.5× / 1× / 2× 仿真速度；详情中的行走位置和提升高度由动画模型同步更新，仍为模拟数值。

## 双层伸缩货叉与作业顺序

载货台正中安装两条平行货叉，每条有上下滑动层。单伸只移动上层，下层保持归中；双伸时下层和上层相对下层同时同向运动，上层绝对行程为两级行程之和。左/右伸分别为模型 Z 轴负/正方向。示意单级行程 2.5 m，并非设备实测参数。

演示循环：定位取货 → 伸叉取货 → 顶升托盘 → 收叉取货 → 定位放货 → 伸叉放货 → 落放托盘 → 收叉归中。X/Y 定位期间 Z 轴归中；伸缩期间 X/Y 不动，仅取放时有微量升降。模式/方向切换会重新开始演示周期，暂停与速度控制作用于整个周期。蓝色托盘随顶层货叉取放，循环开始时重置演示托盘。当前为独立机构演示，不是库存变更、碰撞检测或真实 WCS 调度仿真。

运动学验证：`node --test tests/motion.test.js`。涵盖两种模式、两个方向、行走互锁、归中和阶段连续性。

## 货架与堆垛机生成 / 输送线出库

点击场景工具栏「配置 / 生成」选择 1–4 台堆垛机、4–16 列货架及 2–6 层货架。每台设备对应一条巷道，单伸每巷道 2 排货架，双伸每巷道 4 排货架；生成会重建场景并同步更新设备、任务、货位统计。配置保存在当前浏览器 localStorage，刷新可恢复。未点击生成的表单编辑不会影响现有场景。

出库动作的放货目标是巷道末端的滚筒输送线：堆垛机收叉后带货行走、下降定位，向所选一侧的输送线伸叉，降载放货，再收叉，托盘沿输送线送出。输送线交接位置随单伸/双伸演示行程调整，支持左右出库。当前为参数化示意布局，不代表真实输送线或双深货架的工程尺寸；重复循环会重置演示托盘，不更新真实库存。

## 单伸 / 双伸货架布局

在「配置 / 生成」中选择货架深度：单伸每侧一排，双伸每侧两排。场景中的单伸/双伸切换也会同步重建货架布局，保存模式并重新开始周期。货架列数仍表示沿巷道方向的货位数量，不因深度模式而减少；变化的是巷道左右两侧的深度排数。

一巷道双伸横断面按 Z 轴从负到正排列：1 排（左远位）→ 2 排（左近位）→ 堆垛机 → 3 排（右近位）→ 4 排（右远位）。单伸：1 排 → 堆垛机 → 2 排。各巷道独立生成，排号全局递增且不共享排。单伸伸叉到近位，双伸伸叉到远位；示意中心距离为 2.5 m 和 5 m。地面标注排号与巷道号，生成面板展示各巷道左右排号；统计、任务来源、轨道、输送线和相机范围使用同一布局数据。旧浏览器配置没有深度字段时默认双伸。

货架改为横梁、承托梁和侧向斜撑组成的开放式框架。尺寸、取货过程及库存仍为示意，尚未处理双深取货时近位托盘的真实调度与避让。

## 堆垛机外观细化

细化黄色立柱翼缘、金属导轨、行走轮、双层货叉滚轮/齿条、传动轴、带散热筋的提升与行走电机、控制柜、检修格栅、铭牌、指示灯及黑黄警示条纹。蓝色托盘采用九脚底座和网格面结构。视角菜单提供「设备全貌」观察整机，「设备特写」跟随载货台；两种设备视角都会隐藏遮挡货架，复位恢复全景。模型按用户提供的结构图和视频细化，为几何示意模型，不是厂家 CAD。既有单伸/双伸、左右伸缩、输送线出库和布局配置继续使用同一运动与场景逻辑。

## 屏幕自适应与展示模式

桌面宽度 ≥1280px 且高度 ≥680px 时，看板按 `100dvh` 分配标题、指标、三维主区域、任务列表和页脚的高度，侧栏及任务内容在区域内滚动。短窗口和平板采用正常页面滚动与面板重排；宽度 ≤599px 时优先展示三维场景、加大触控按钮，任务表格可横向滚动，页面不横向溢出。工具栏使用正常文档流，随宽度自动换行，不覆盖三维画布。

「专注场景」暂时隐藏指标和侧栏，点击「完整看板」恢复；标题栏「全屏」使用浏览器 Fullscreen API，Escape 可退出，权限或浏览器不支持时显示提示。图表和三维画布由 ResizeObserver 随容器调整；未手动操作相机时全景按模型边界自动取景，复位重新启用自动取景。超高清屏幕将三维绘制像素数控制在约 300 万以内；仿真暂停且相机不变化时不重复绘制场景。

验证尺寸：1920×1080、1366×768、2560×1440、768×1024、390×844、320×568、844×390。桌面无页面纵向滚动，全部尺寸无页面横向溢出及工具栏重叠；较长侧栏仍需要局部滚动。移动端可使用专注场景扩大三维操作区域。

## 设备异常报警（本地演示）

选择设备，在详情中点击「模拟取货报警」。该设备进入伸叉取货阶段后触发 FORK-101「取货货叉驱动异常」：设备独立停机，其他设备继续；模型指示灯和轮廓变红，顶部显示设备报警标签，设备卡片、任务状态与可用率同步更新。三维场景中的报警提示条在专注模式仍显示，点击可定位设备。待触发的演示可取消。

标题栏「报警」打开报警中心，显示设备编号、巷道、报警码、发生阶段、时间和状态。「确认报警」仅确认阅读，不解除停机；「演示故障复位」解除该设备的本地故障，按当前全局运行/暂停状态继续。已复位记录保留在当前页面会话，刷新会清空，不属于服务器持久化日志。存在报警或待触发演示时，禁用场景生成和货叉布局/方向切换，避免重建清除故障。真实 PLC/WCS 报警源及设备复位接口尚未接入。

全部逻辑测试：`node --test tests/*.test.js`，包含报警只触发一次、停机隔离、暂停、取消和复位恢复。
